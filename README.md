# Movie-Recommender-System
“A Streamlit-based Movie Recommendation System using TMDB API”

This is a simple **Movie Recommendation System** built using **Python** and **Streamlit**.  
It recommends movies similar to the one selected by the user and displays their posters using the **TMDB API**.

---

## ⚙️ Features
- Suggests top 5 movies similar to the selected movie  
- Displays posters fetched from TMDB API  
- Built with Streamlit for a clean and interactive interface  

---

## 🧠 Technologies Used
- Python  
- Streamlit  
- TMDB API  
- Pandas, scikit-learn, pickle
- dataset link = https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata
